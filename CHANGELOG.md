# Changelog

## 2.0.0 — 2026-08-29

- Replaced regex-only matching with a non-executing manifest tokenizer.
- Added NUI, `files`, `data_file`, dependency, glob, duplicate, `lua54`, and `node_version` checks.
- Added stable rule IDs shared with the hosted browser validator.
- Added text/JSON output, `--version`, `--fail-on-warnings`, and defined exit codes.
- Added dependency-free unit and CLI tests plus versioned ruleset fixtures.
